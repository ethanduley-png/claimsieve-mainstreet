# Founder OS Acceptance Criteria

The merged slice is accepted only when:

- all v0.33 Python and Node tests still pass;
- the Founder OS Python and Node tests pass;
- repository, title, and body mutation after approval are blocked;
- missing work-item or destination evidence is denied;
- policy substitution and permit replay are blocked;
- timeout before commit remains unknown;
- timeout after commit is confirmed only by independent readback;
- automatic retry remains false;
- all four Founder OS ledger chains verify;
- MainStreet contains no GitHub SDK, fetch call, credential, permit, or execution path;
- the original Founder OS authority is not imported by active code;
- any live GitHub claim is limited to redacted, retained evidence for the exact authorized action;
- a clean extracted archive reproduces every available gate.
