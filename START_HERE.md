```text
  -> signed work-item and repository evidence

  -> exact human approval
  -> v0.33 permit authority
  -> durable one-use reservation

  -> independent readback
  -> four ledgers
```

## Hard stop conditions

Stop rather than improvise if a proposed change:

- introduces another permit issuer;
- gives MainStreet or OpenClaw provider credentials;
- treats executor output as terminal outcome truth;
- retries an unknown GitHub issue creation automatically;
- weakens exact repository or payload binding;
- claims live GitHub validation without a credentialed, explicitly authorized test;
- describes uncompiled Rust or Rocq as executed assurance.
